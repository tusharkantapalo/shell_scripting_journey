## ▶️ Getting Started

### 1️⃣ Prerequisites

Before running the scripts, make sure you have:

- 🍎 macOS or another compatible Unix-like operating system
- 🐚 Bash installed
- 💙 Visual Studio Code (recommended)
- ⌨️ Terminal access

macOS includes Bash, although its default interactive shell is Zsh. You can check whether Bash is available by running:

```bash
bash --version
```

### 2️⃣ Clone the Repository

```bash
git clone https://github.com/tusharkantapalo/shell-scripting-journey.git
```

### 3️⃣ Navigate to the Project

```bash
cd shell-scripting-journey
```

### 4️⃣ Run a Shell Script

For example, to execute `hello.sh`:

```bash
bash hello.sh
```

Alternatively, make the script executable:

```bash
chmod +x hello.sh
./hello.sh
```

### 5️⃣ Open the Project in VS Code

```bash
code .
```

If the `code` command is configured on your Mac, this opens the current project in VS Code. Otherwise, open the folder directly through the VS Code application.

## 🧪 Example Script

Here is a simple Bash program that demonstrates variables, user input, and output.

```bash
#!/bin/bash

echo "🐚 Welcome to Shell Scripting!"

read -p "Enter your name: " name

echo "Hello, $name!"
echo "Keep learning and keep building. 🚀"
```

**Run the program:**

```bash
bash hello.sh
```

**Example output:**

```text
🐚 Welcome to Shell Scripting!
Enter your name: Tusharkanta
Hello, Tusharkanta!
Keep learning and keep building. 🚀
```
